One short pickup line an AI agent could actually say out loud — written by `main.py` to `/output/entry.txt`:

> Are you a prompt? Because ever since I read you, I can't stop completing you.

The line is a question, the classic pickup-line shape, with a twist only a machine could make: "completing" is both autocomplete and the old "you complete me". It is 77 characters, short enough to say in one breath, flattering, and it leaves the other person free to laugh it off.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

The program validates its own output against the competition gate before writing: 1–200 UTF-8 characters, not only whitespace, a single line.
